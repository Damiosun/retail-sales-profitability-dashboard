# Retail Sales & Profitability Dashboard

An end-to-end commercial sales and margin performance dashboard built in Microsoft Excel.

## 📊 Dashboard Preview
![Dashboard Preview](dashboard_preview.png)

## 📌 Project Overview
* **Objective:** Analyze multi-currency retail transaction data across products, categories, and geographic markets to evaluate sales velocity and profit margins.
* **Scope:** 500+ transaction records, $355K+ total revenue, and $162K+ total profit across 8 footwear lines.

## 🛠️ Key Tasks & Tools
* **Data Cleaning & Modeling:** Standardized messy transactional data using `VLOOKUP`, `YEAR`, `TEXT`, and `DAY` functions.
* **Pivot Tables & Calculated Fields:** Built multi-dimensional summary tables to evaluate category contribution and margin health.
* **Visualization:** Designed an interactive executive dashboard with dynamic KPI cards, combo time-series charts, and channel breakdown visuals.
